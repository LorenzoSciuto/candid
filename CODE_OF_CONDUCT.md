# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainers through GitHub (**Security → Report a vulnerability** works for confidential reports too). Reports are handled confidentially, and maintainers may remove content or block participants who break these rules.
